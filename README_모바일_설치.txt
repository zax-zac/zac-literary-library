강작가 문학 서재 모바일 v0.1

1. 이 파일은 모바일용 정적 웹앱(PWA) 소스입니다. ZIP 자체가 APK 설치 파일은 아닙니다.
2. GitHub Pages 등 HTTPS 정적 호스팅에 이 폴더 안의 파일을 올린 뒤 갤럭시 크롬에서 주소를 엽니다.
3. Chrome 메뉴 > 홈 화면에 추가 > 설치 (기기 및 Chrome 버전에 따라 명칭이 다릅니다).
4. URL/본문 붙여넣기 → ChatGPT 번역용 복사 → 번역문 붙여넣기 → 저장/EPUB.
5. 서재 백업 JSON을 Google Drive로 옮겨 엣지용 v0.4에서 가져오거나, 반대로 사용합니다.
6. 백업 JSON에는 원문/번역문이 포함됩니다. 공유 링크 공개 금지 및 타인 접근 주의.
7. 자동 클라우드 동기화 아님. 브라우저 저장 데이터 삭제 전 반드시 백업하세요.
8. 크롬에서 다른 사이트의 본문을 자동 추출하지는 않습니다. 사이트에 따라 텍스트 선택/복사 또는 공유 URL을 사용하세요.
